# 둘만의 7장 포커

2명이 각자 카드 7장을 받고, 30초 뒤 자동으로 카드를 공개해 최선의 5장 족보로 승부하는 웹게임입니다. 베팅 기능은 없습니다.

## 기능
- 서버에서 암호학적 난수 기반으로 52장 덱을 섞음
- 한 라운드에 중복 없이 각자 7장씩 배분
- 카드 정보는 각 플레이어의 소켓에만 전송되어 게임 중 상대방에게 보이지 않음
- 라운드 시작 30초 뒤 서버에서 자동 공개 및 승패 판정
- 7장 중 5장 조합 21개를 비교해 최선의 족보를 판정
- 같은 방에서 다시 한 판 가능

## 로컬 실행
Node.js 18 이상이 필요합니다.

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000`을 엽니다. 두 사람이 같은 컴퓨터/네트워크에서 테스트할 수 있습니다. 서로 다른 네트워크에서 접속하려면 아래처럼 인터넷에 배포해야 합니다.

## 인터넷 배포 예시: Render
1. 이 폴더를 GitHub 저장소에 올립니다.
2. Render에서 **New + → Web Service**를 선택하고 저장소를 연결합니다.
3. Build Command는 `npm install`, Start Command는 `npm start`로 지정합니다.
4. 배포가 끝나면 Render가 제공한 HTTPS 주소를 두 사람이 각각 엽니다.
5. 한 사람이 방을 만든 뒤 5자리 코드를 카톡으로 보내고, 다른 사람이 그 코드를 입력해 입장합니다.

Render 및 기타 호스팅 서비스의 무료 플랜, 잠자기 정책, 가격은 변경될 수 있습니다. 서비스 대시보드의 현재 조건을 확인하세요. 이 앱은 방/게임 데이터를 메모리에 보관하므로 서버가 재시작되면 진행 중인 방이 사라집니다. 단일 인스턴스로 배포하세요.

## 게임 방법
1. 각자 이름을 입력합니다.
2. 한 명이 `새 게임 만들기`를 누르고 방 코드를 카톡으로 전달합니다.
3. 친구가 같은 코드로 입장하면 자동으로 카드가 배분되고 30초 타이머가 시작됩니다.
4. 각자는 본인의 카드 7장만 확인할 수 있습니다.
5. 30초 후 모든 카드가 자동 공개되고 서버가 족보를 판정합니다.
6. `다시 한 판`을 눌러 다음 라운드를 시작합니다.

## 보안/운영 메모
- 방 코드는 무작위로 생성되지만 로그인/계정 인증 기능은 없습니다. 아는 사람끼리만 코드를 공유하세요.
- HTTPS를 제공하는 호스팅 서비스를 사용하세요.
- 게임 도중 브라우저를 닫거나 연결이 끊기면 라운드가 정상 진행되지 않을 수 있습니다. 재접속 복구는 기본 구현에 포함하지 않았습니다.
- 이 앱은 가상 카드 족보 게임이며 결제/현금 베팅 기능이 없습니다.
